# Системы управления: учебные проекты

Студент 4 курса ЕНУ, специальность «Автоматизация и управление».
Здесь собраны мои учебные проекты по моделированию и управлению.

## Проекты

### Линия склеивания мебельных щитов
Имитационная модель производственной линии: потоки заготовок, станки, очереди, загрузка оборудования.
Инструменты: AnyLogic. Тип работы: курсовой проект.

### Система управления температурой горячего пресса
Модель объекта и контура регулирования температуры, настройка ПИД-регулятора.
Инструменты: MATLAB, Simulink. Тип работы: курсовой проект.

### Нечёткий ПИ-регулятор и классический ПИД
Сравнение двух подходов к управлению на одной модели.
Инструменты: MATLAB, Simulink, Fuzzy Logic. Тип работы: лабораторная работа.
